## sqlalchemy 用法
推荐组合
表格
场景	方法	为什么
查多条	result.scalars().all()	返回列表，空也是 []，不会报错
查单条	result.scalar_one_or_none()	有就返回对象，没有返回 None，安全
另外两个什么时候用？
表格
方法	场景	说明
scalar_one()	查单条，必须有，没有就是 bug	比如根据主键查，理论上一定存在
scalars().first()	查排序后的第一条	比如"最新的一个"、"最贵的一个"


表格
操作	需要 commit()	需要 refresh()	说明
SELECT 查询	❌ 不需要	❌ 不需要	只读，不涉及数据变更
session.add(obj)	✅ 需要	可选	把对象加入会话，但还没写入数据库
session.delete(obj)	✅ 需要	❌ 不需要	删除后不需要刷新
UPDATE (修改属性)	✅ 需要	可选	SQLAlchemy 会追踪变更

result = await session.execute(select(Hero)) execute() 是异步操作，必须 await。它执行 SQL 语句，返回结果。

session.add(team)           # ❌ 不需要 await，只是"标记"要插入
await session.commit()      # ✅ 需要 await，真正执行 SQL 写入
await session.refresh(team) # ✅ 需要 await，从数据库重新读取（获取自增ID等）
