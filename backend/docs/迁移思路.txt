阶段 7 — 05 会话 + 01 调试流式
会话列表/消息/删改/置顶；再做 SSE 对话与 stop（最难，单独成批）。

阶段 8 — 11 工作流
CRUD + draft-graph + publish；debug 流式可后置。

阶段 9 — 09 OpenAPI
API Key CRUD + /openapi/chat。

阶段 10 — 08 + 10
优化 Prompt、建议问题、应用广场；依赖已有应用能力，可穿插在 3–6 之间做。

## 每批迁法

1. 对照文档定路径与字段（前缀已定 `/api/v1` + 前端 prefix）  
2. Schema → Service → Router  
3. 需登录的挂 `Depends(get_current_account)`  
4. 成功 `ok(...)` / 分页 `page_data(...)`；失败 `raise NotFoundException` 等
